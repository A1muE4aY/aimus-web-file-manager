# tests/e2e 目录索引

端到端测试：真实浏览器（无头 Edge + 无痕 + 全新临时配置目录）驱动完整链路
「浏览器 → 本机 HTTP 服务 → SSH/SFTP → 远程文件系统」。

| 文件 | 作用 | 需要 WSL 测试床 |
| --- | --- | --- |
| support.py | 标准库实现的 CDP over WebSocket 客户端与 Edge 启动器；页面辅助函数（`wait_for` 的表达式紧跟 `navigate()` 时必须容忍 DOM 尚未解析，见 `docs/reports/PHASE-06-CU-ACCEPTANCE-v012.md` §4.6） | 否 |
| test_browser_flow.py | 浏览器里的连接、目录浏览、主机密钥确认、密码提示与失败上报 | 前两个类需要 |
| test_browser_regressions.py | 阶段一缺陷②③的浏览器回归：远端目录消失后的「已过期」列表与重试入口；已有活动连接时新建连接不得把文件区打回占位页 | 是 |
| test_browser_sidebar.py | 阶段二侧边栏：窄/常规/宽三种宽度下的布局、长名称换行不重叠、四种连接状态一眼可分 | 是 |
| test_browser_search.py | 阶段三检索界面（4 项）：搜索 → 结果表（名称/类型/所在目录/大小/修改时间）→ 定位跳转并高亮 → 大小写不敏感与无匹配提示 → 清空 → 中止并释放连接 |
| test_browser_layout.py | v0.1.2 阶段二的文件列表布局与右键菜单（8 项）：操作按钮在目录行 / 压缩包行 / 符号链接行上仍落同一格且不压名称；长中英文名截断后悬浮与键盘焦点都能看全名、复制名称与复制完整路径都带真实路径；截断只影响显示（预览 / 编辑 / 重命名请求里是完整真名）；右键出的是自绘菜单且认得目标（文件 / 压缩包 / 目录 / 断链四种菜单项逐一核对）；Escape、点外部、切换目录三条关闭路径；搜索框与编辑器里原生菜单原样保留；只读连接上写操作灰掉并说明原因；窄窗（992px）与 150% 缩放（661px）下按钮不出视口、无横向滚动 | 是 |
| test_browser_edit.py | 阶段四编辑与操作列（5 项）：操作列「编辑」→ 改内容 → 保存后远端字节与界面大小列同步；别人改过远端时冲突提示且不覆盖、可重新加载；取消前先问「放弃修改」；重命名 / 压缩 / 解压 / 删除走对话框；只读连接上编辑可用而重命名、压缩、删除为灰 | 是 |
| artifacts/ | 运行时截图产物（不入库，可随时删除） | - |

运行方式：

    python -m unittest discover -s tests/e2e -t .

没有装 Edge 或没有测试床时相关用例自动跳过（不是失败）。
