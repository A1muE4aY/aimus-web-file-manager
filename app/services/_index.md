# app/services/ 索引

用例层：把连接层的原语编排成 API 层要的操作，并持有进程内的会话状态。

| 文件 | 用途 |
|---|---|
| `connection_manager.py` | 连接配置的增删改查 + 会话注册表；删除连接前先断开；活动会话达到 `ssh.max_sessions` 时回收最早的一条 |
| `session.py` | 一条远程会话：状态机（idle/connecting/connected/error）、时长、最近错误、SFTP 客户端句柄 |
| `filesystem.py` | 目录浏览与文件元数据：排序、截断、符号链接标记、预览读取、写入门禁（`allow_write`） |
| `transfer.py` | 上传与下载：流式收发、大小上限、临时文件 + 原子改名（决策 D-007） |
| `editor.py` | 远端文本文件的在线编辑（v0.1.1）：大小上限（`security.max_edit_bytes`）、二进制与目录拒绝、UTF-8 严格解码（解不出来就报错、不猜编码）、BOM 与换行风格记忆、保存前重查写权限、按 sha256 或 mtime 检测外部改动（冲突即拒绝覆盖） |
| `fileops.py` | 条目级文件操作（v0.1.1）：重命名、删除（递归需显式确认）、压缩成 `.tar.gz`、解压（`.tar.gz`/`.tgz`/`.tar`/`.zip`）。全部在本地进程内流式完成，远端只收发字节；解压拒绝目录穿越（`..` 与绝对路径）、不跟随符号链接、跳过已存在项 |
| `search.py` | 远端文件名检索（v0.1.1）：后台线程逐目录列举（只走既有 SFTP 通道，不在远端执行命令）、命中/目录/条目/时长四道预算与截断、跳过读不到的目录、符号链接只报不跟随、随时可中止、同一连接同时只允许一个检索 |
