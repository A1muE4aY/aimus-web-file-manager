# AWFM 需求规格

- 版本：v0.1.0 · 状态：**已确认**（用户于本次会话确认 5 项初始化选择）
- 来源：规划文档 §1/§3/§7/§10/§11 + 用户确认结论

## 0. 已确认的初始化决策

| 项 | 结论 |
|---|---|
| 宿主机环境 | Windows 本机（VMware Workstation 场景） |
| 目标虚拟机 | **Linux 优先**，集成测试用本机 CentOS Stream 10 虚拟机 |
| 交付方式 | 源码开发 + **便携版**交付 |
| SSH 认证 | **密钥优先，同时支持密码** |
| SSH 实现 | **系统 OpenSSH 子进程**（`ssh.exe` / `sftp.exe`），后端纯 Python 标准库 |

## 1. 功能需求

### 1.1 P0 — 基础版本（必须实现，是 v0.1.0 的验收范围）

| 编号 | 需求 | 验收方式 |
|---|---|---|
| F-P0-01 | 配置 SSH 主机地址、端口、用户名及认证方式（密钥文件 / 密码 / ssh-agent） | 配置写入后重启服务仍生效 |
| F-P0-02 | 连接、断开、重连与连接状态展示 | 状态在 `GET /api/connections` 中可读且与真实链路一致 |
| F-P0-03 | 浏览远程目录、进入子目录、返回上级 | 目录列表内容与目标机 `ls -la` 一致 |
| F-P0-04 | 显示文件名、类型、大小、修改时间 | 抽查 5 个条目与 `stat` 输出一致 |
| F-P0-05 | 显示连接错误、权限错误、目录不存在等信息 | 三类错误均给出可理解提示且服务不崩溃 |
| F-P0-06 | 本地配置保存与读取 | `data/config.json` 原子写入，损坏时可报错而非静默重置 |
| F-P0-07 | 基础日志、健康检查、离线运行 | `GET /api/health` 正常；断网后全部核心流程仍可用 |

### 1.2 P1 — 实用版本

| 编号 | 需求 |
|---|---|
| F-P1-01 | 文件与目录下载到本地（流式，不整份读入内存） |
| F-P1-02 | 文件上传到远程目录（流式，有大小上限） |
| F-P1-03 | 文本文件预览（编码探测 + 大小上限） |
| F-P1-04 | 文件名排序、路径导航与刷新 |
| F-P1-05 | 大文件下载进度与传输取消 |
| F-P1-06 | 文件大小、人类可读时间格式 |
| F-P1-07 | 多虚拟机配置管理 |

### 1.3 P2 — 扩展版本（稳定性验证后）

创建目录、重命名、删除文件；文本编辑保存；权限与属主展示；多连接会话；压缩与批量传输；操作审计与会话历史。

> P2 中的**删除、覆盖、编辑**具有高风险，必须在只读浏览与传输功能稳定后单独设计，
> 并且必须带二次确认、路径检查与操作记录（规划文档 §3.2）。

### 1.4 首版明确不做

在线编辑器、终端模拟器、远程命令执行面板；用户注册与云端同步；数据库、消息队列、微服务；
前后端分离部署；复杂权限平台；自动下载依赖与在线更新。

## 2. 非功能需求

| 编号 | 需求 | 量化门槛 |
|---|---|---|
| N-01 | 离线可用 | 不产生任何必需的外部网络请求 |
| N-02 | 轻依赖 | 后端运行时依赖数 = 0（仅 Python 3 标准库）；系统 OpenSSH 视为环境前提 |
| N-03 | 默认安全 | 默认绑定 `127.0.0.1`；不接受浏览器传入的任意远程命令 |
| N-04 | 可测试 | 每个 P0 需求至少有 1 个自动化用例或手工测试记录 |
| N-05 | 资源受控 | 文件大小、并发连接、超时、临时文件均有显式上限 |
| N-06 | 日志脱敏 | 密码、私钥内容、令牌不出现在日志与 API 响应中 |
| N-07 | 可移植 | 配置文件与路径不硬编码盘符，可用 `--config` / `--data-dir` 重定向 |

## 4. 发布门槛（规划文档 §7.3）

- P0 功能测试全部通过。
- 所有高风险安全问题已修复，或有明确的发布阻断决定。
- 离线环境中无必需的外部网络请求。
- 所有第三方依赖均已登记；本项目声称为**零第三方依赖**，因此必须有依赖清单与实际验证支持。
- 新环境部署步骤可由另一位使用者独立复现。
- 用户文档中每条启动、停止、连接及故障排除指令均经过验证。
- 所有未通过或未执行的测试如实记录，**不以通过率掩盖阻断性问题**。
